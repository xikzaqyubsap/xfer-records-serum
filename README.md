## Overview

Xfer Records Serum is the definitive wavetable synthesizer used in modern electronic music production, offering a high-quality wavetable engine, analog-modeled filters, and a deep built-in effects chain.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Xfer Records Serum** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Wavetable Engine** | High-resolution wavetable oscillators with per-frame editing and morphing |
| **Analog Filters** | Multiple filter types including the coveted Serum Analog filter |
| **Mod Matrix** | Extensive drag-and-drop modulation to any parameter from any source |
| **FX Rack** | Eight built-in effects per instance including distortion, reverb, and chorus |
